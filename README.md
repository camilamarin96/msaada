# Msaada website

Clickable prototype of the Msaada (Circular Community Support Initiative) website, made to review the design before building the production site.

## Pages

- Home
- About us (includes "Where your donation ends up")
- Sessions
- What can you donate?
- Our process
- Contact & get involved

## View it

Open `index.html` in a browser. Navigation between pages works, and so do the WhatsApp and phone links. The contact form shows its confirmation screen but sends nothing.

To publish it online, turn on GitHub Pages: Settings › Pages › Deploy from a branch › `main` / root.

## Folders

- `index.html`: the whole prototype in one page. Pages are switched with the address hash (`#/about`, `#/contact`, ...).
- `img/`: logo and photos.
- `design/`: source files of each page from the Claude Design canvas (`.dc.html`) and the canvas index (`canvas.json`). The prototype is built from these.
